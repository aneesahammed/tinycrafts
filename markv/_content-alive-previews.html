Markdown content, alive

The markdown source stays plain text. What changes is how it renders. Diagrams draw themselves, charts grow into view, headings stroke in their accent line. Every example below shows the markdown source, then the static rendering, then the rendering with motion.

Content-level motion · not chrome
01

Mermaid flowcharts that draw themselves

Your example. Nodes fade in first, then edges draw between them in sequence — like watching someone explain the diagram on a whiteboard. The flow becomes visible motion.

Markdown ```mermaid
graph TD
  A[Editor] --> B[Parser]
  B --> C[Renderer]
  C --> D[Preview]
```
Static
With motion
Why A static flowchart is a snapshot — you read labels to figure out the direction. An animated one tells you the direction in two seconds, before you read a single label. Same markdown source; vastly more communication.
02

Sequence diagrams that play their messages in order

Lifelines appear first. Then each message flies between actors in the order it happens. The temporal flow becomes literal.

Markdown ```mermaid
sequenceDiagram
  User->>App: Open file
  App->>Parser: Parse
  Parser-->>App: AST
```
Static
With motion
Why Sequence diagrams are inherently about time. Drawing them all at once hides their best feature. Playing them in order is the diagram explaining itself.
03

Headings whose accent line draws itself in

When a heading scrolls into view, a thin accent under it strokes from left to right. Quiet signal that says “new section.”

Markdown ## The compiler is not a magic box
Static
The compiler is not a magic box

It reads your code, checks the rules, and produces a smaller version. Nothing more.

With motion
The compiler is not a magic box

It reads your code, checks the rules, and produces a smaller version. Nothing more.

Why The eye registers the line being drawn unconsciously. It signals “something starts here” without shouting. Multiply by twenty headings in a long document and reading feels less monotone.

The thesis

Your markdown source stays plain text — three backticks for mermaid, three backticks for chart, two hashes for a heading. What markv does on render is make those elements arrive with motion instead of slamming into place. Same portable markdown. A document that feels alive.
