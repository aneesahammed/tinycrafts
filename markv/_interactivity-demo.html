The quiet power of interactive reading

Markdown renders as static HTML by default. With a few small additions — stagger, focus, callouts, sidenotes, code affordances — the same document starts to feel like a place rather than a page.

Most reading tools mistake interactivity for spectacle: parallax, confetti, cursor trails. Those make documents feel like billboards. The opposite move — quiet motion that disappears once you've noticed it — is what good editors aim for¹.

The features below are each small. Together they shift the experience from "reading rendered text" to "being in a document."

Stagger reveal

Watch the page load. Paragraphs don't appear all at once; they cascade in at 40-millisecond intervals. The effect is invisible consciously and felt subconsciously — the document arrives instead of slamming into place. Hit "Replay stagger" in the top bar to see it again².

Sidenotes in the margin

On wide screens, footnotes float into the right margin near their reference. Hover the ¹ or ² marks above and watch the matching sidenote highlight. This is the Tufte / Gwern pattern — distinctive to writing tools and rare in markdown editors.

On narrow screens the sidenotes collapse to inline footnotes at the bottom (resize this window to test).

Callouts as directives

Add a small DSL on top of CommonMark for typed callouts: :::note, :::warn, :::tip. Authors get a vocabulary; readers get visual hierarchy.

Note

This callout uses a teal accent and an ℹ glyph. Markdown source would be three lines: :::note, body, :::.

Warning

Warmer accent. Use sparingly — the visual weight is high.

Tip

Indigo accent. Best for "here's the trick" inserts inside longer explanations.

Why not just use blockquotes for callouts?

Blockquotes carry semantic weight ("this is a quote"). Callouts carry intent ("read this carefully"). Conflating them costs you both. The directive syntax is also greppable in source.

Code blocks with copy

Click the Copy button. It briefly turns green to confirm. Tiny affordance, big quality-of-life gain over the default highlight- and-select dance.

Focus mode

Click "Focus mode" in the top bar, then scroll. Whichever paragraph is centered in the viewport stays bright; the others dim and blur ever so slightly. Single-paragraph attention for long documents.

The implementation uses IntersectionObserver to track which element is closest to the viewport center, then toggles a class. No continuous scroll handlers, no jank³.

The best interactive details are the ones you stop noticing within three days of use.
