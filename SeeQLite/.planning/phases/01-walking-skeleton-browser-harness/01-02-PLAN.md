<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local File/main thread → worker | Untrusted bytes cross once through a transferable buffer. |
| Main thread → worker command protocol | UI-controlled timing and lifecycle messages must not bypass typed command bounds. |
| Worker → React state | Errors/results are untrusted and must be bounded, normalized, epoch-checked DTOs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-05 | Tampering | worker envelopes | mitigate | Discriminated guards, request ID/epoch checks, unknown/duplicate response rejection. |
| T-01-06 | Information disclosure | file/result handling | mitigate | Transfer bytes, retain File only in memory, no logging/storage/network/URL propagation. |
| T-01-07 | Denial of service | worker lifecycle | mitigate | One serialized worker, fixed query, explicit termination and pending settlement. |
| T-01-08 | Elevation of privilege | main-thread SQLite access | mitigate | SQLite package import confined to worker; source/bundle scan and runtime instrumentation. |
| T-01-SC | Tampering | SQLite package | mitigate | Exact official pin/lock and package-source evidence from STACK.md. |
</threat_model>
