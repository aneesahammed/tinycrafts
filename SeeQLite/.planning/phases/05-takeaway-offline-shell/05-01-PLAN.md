## Trust Boundaries

| Boundary | Untrusted input crossing it |
|---|---|
| Held SQLite result → encoder | Names, text, BigInt, BLOB previews, truncation metadata, inconsistent/unknown DTO kinds |
| Encoder → downstream spreadsheet/parser | CSV formula starters, delimiter/control characters, duplicate labels, lossy NULL/empty semantics |
| Encoded bytes → browser download APIs | Hostile filename, oversized bounded Blob, click/object-URL lifecycle failures |
